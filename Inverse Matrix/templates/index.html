How it works

The method behind the calculator

Ek ··· E2E1A = I

therefore

A−1 = Ek ··· E2E1

The three row operations
Row operationNotationEffect on det
Swap two rowsRi ↔ Rjchanges the sign
Multiply a row by c ≠ 0Ri ← (c) Rimultiplies by c
Add a multiple of another rowRi ← Ri + (c) Rjno change
  1. Work column by column. Find a nonzero number on or below the diagonal, swapping rows if needed.
  2. Divide that row so the diagonal entry is 1, then make every other entry in the column 0.
  3. If a column has only zeros on and below the diagonal, the matrix is singular and has no inverse.
  4. Every step is also applied to the identity matrix. When A has become I, the identity has become A−1.
